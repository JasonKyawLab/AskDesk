AskDesk widget — demo page

The chat bubble in the bottom-right is the embeddable widget, loaded with one line. Paste your public API key below and reload to try it.

To embed it on any site, add:

<script src="https://YOUR-HOST/widget.js"
        data-key="YOUR_PUBLIC_API_KEY"></script>

Optional attributes: data-api (API host, defaults to the script's origin), data-color (accent colour), data-logo (header logo URL), data-position (left or right), data-telegram (a t.me link for the "continue on Telegram" handoff).
